# 営業プレイブック

## ターゲット顧客
SNS運用が弱い中小企業・個人事業主・展示会出展企業・EC事業者・店舗ビジネス・士業・美容・建築・飲食・
スクール・コンサル・地方企業・採用に困っている会社。

## 営業フロー
```
問い合わせ/リード獲得
  → 企業取得（company_research.py で自動分析）
  → 一次返信（sales_email_generator.py, stage=cold）
  → 診断提案（サービス①, ¥50,000〜, 24h納品）
  → 診断送付後フォロー（stage=follow_up）
  → 見積送付（estimate_generator.py）
  → クロージング（stage=closing）
  → 契約（CRM登録, business/contracts/）
  → キックオフタスク生成（business/api の /api/tasks）
  → 納品・月次レポート（report_generator.py）
  → アップセル提案（stage=upsell, 3ヶ月継続後）
  → 契約更新（stage=renewal, 更新45日前に自動リマインド）
```

## クロージングの原則
1. 初回は必ずサービス①（¥50,000〜、24h納品）から入り、即決ハードルを下げる
2. 診断結果を基に、具体的な数値改善余地を示してから②〜⑤を提案する
3. 「今すぐ客」でなくても3回まではフォローし、以降は休眠(dormant)に分類する
4. 成約時は必ず次のアップセル候補をCRMにタスク登録する（Salesエージェントの判断基準）

## 業種別トークのポイント
- 美容/飲食/店舗: 「毎回投稿を考える時間が無くなる」を訴求
- 士業/建築: 「事例発信で問い合わせが増える」を訴求（実績ベース、誇大表現は禁止）
- EC: 「カゴ落ち・CVRの数値改善」を訴求
- 展示会出展企業: 「名刺交換後のフォローが自動化される」を訴求
- 採用に困っている会社: 「SNS発信が採用ブランディングにもなる」を訴求
