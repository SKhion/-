# 見積書テンプレート

`business/scripts/estimate_generator.py` が自動生成する項目。手動作成時も以下に従う。

| 項目 | 内容 |
|---|---|
| 宛先 | {会社名} 様 |
| 発行日 | {YYYY-MM-DD} |
| サービス | {サービス名} |
| 数量 | {数量} |
| 単価（税抜） | ¥{単価} |
| 合計金額（税抜） | ¥{合計} |
| 消費税(10%) | ¥{消費税} |
| 税込合計 | ¥{税込合計} |
| 支払条件 | 契約後7日以内 / 月額は前月末締め翌月末払い |
| 有効期限 | 発行日より30日間 |

利益率が50%を下回る場合は自動で警告が付与され、Financeエージェント経由でCEOへ差し戻される。
