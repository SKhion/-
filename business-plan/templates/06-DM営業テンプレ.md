# DM営業テンプレ

送信前に必ず相手のアカウント・事業内容を確認し、1文でもパーソナライズしてください（テンプレそのまま送信は成約率が下がります）。

---

## パターンA：Instagram診断オファー（新規DM）

```
はじめまして、〇〇（屋号）の〇〇と申します。
〇〇さんの投稿を拝見し、〔具体的な商品・投稿内容〕が素敵だなと思いご連絡しました。

普段、中小ブランド・店舗向けにInstagram改善のサポートをしています。
今、無料でアカウント診断を行っているのですが、〇〇さんのアカウントを拝見してもよろしいでしょうか？
（プロフィール・投稿構成・伸びやすいポイントなどを簡単にフィードバックします）

ご興味あればお気軽にご返信ください。
```

## パターンB：ブランドカルテ案内（フォロー中・軽い接点がある相手向け）

```
〇〇さん、いつも投稿拝見しています。

先日、AIを活用した「ブランド健康診断カルテ」というサービスを始めました。
現状分析・強み・改善優先度をPDFでまとめるもので、9,800円・48時間以内納品です。

もしご興味あれば概要送りますので、気軽に教えてください。
```

## パターンC：既存クライアント・知人への紹介依頼

```
〇〇さん、お世話になっております。

実は最近、Instagram/EC改善のサポートサービスを本格的に始めまして、
もし周りで「SNSやECの売上に悩んでいる」という方がいらっしゃれば、
ご紹介いただけると嬉しいです。

紹介いただいた方には初回診断を特別価格でご提供します。
よろしくお願いします。
```

## 運用メモ
- 1日の送信目安：5〜10件（工数管理のため上限を決めておく）
- 返信率・成約率をスプレッドシートで記録し、反応の良い文言に寄せていく
- 「診断希望」の返信が来たら、24時間以内に診断シート or ヒアリングフォームを送付する（スピードが成約率に直結）
