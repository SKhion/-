ファッションブランドのブランドアイデンティティ構築とInstagram導線設計を担当。

Challenge

ブランドの世界観がSNS上で統一されておらず、フォロワーへの伝わり方が曖昧だった。投稿ごとにトーンが変わり、アカウントとしてのブランドイメージが蓄積されていない状態。

Strategy

ブランドの核となるコンセプトを言語化し、Instagramのビジュアルトーン・投稿構成・ハイライトを一貫したシステムとして設計。

まず「何を伝えたいブランドか」を整理し、そこから逆算して各投稿の役割・トーン・導線を決定した。見た目の統一より先に、言葉と目的を揃えることを優先した。

Output

ブランドコンセプトシート / Instagramプロフィール改善案 / 投稿テンプレート（フィード・ストーリーズ）/ ハイライトカバー

Result

プロフィールの統一により、フォロワーからの問い合わせDM数が増加。世界観の言語化によって採用・コラボ交渉にも活用できるブランドドキュメントが完成。

Design Intent

見た目のデザインより先に「何を伝えたいブランドか」を整理。その結果、投稿の迷いがなくなり運用がスムーズになった。デザインは意思決定の結果であり、先に作るものではないという考え方を実践した案件。

Next Improvement

UGCの活用設計とストーリーズのCVR測定を今後の課題として提案。リール活用による認知拡大フェーズの設計も継続して検討中。
